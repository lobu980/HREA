# IM-MOEA 中基于高斯过程的逆建模

## 1. 论文与核心动机

本文所讨论的方法来自 Cheng、Jin、Narukawa 与 Sendhoff 的论文 *A
Multiobjective Evolutionary Algorithm Using Gaussian Process-Based Inverse
Modeling*（IEEE Transactions on Evolutionary Computation, 2015）。论文提出的算法通常简称
**IM-MOEA**。

给定决策向量 \(\mathbf{x}\in\mathbb{R}^{D}\) 和目标向量
\(\mathbf{f}(\mathbf{x})\in\mathbb{R}^{M}\)，常规代理模型学习正向映射

\[
  \mathbf{x}\longmapsto\mathbf{f}.
\]

IM-MOEA 反过来学习

\[
  \mathbf{f}\longmapsto\mathbf{x}.
\]

这样做的目的并不是求原目标函数的解析逆，而是利用当前优良解学习“Pareto 前沿附近的目标点如何对应到
Pareto 解集附近的决策点”。算法先在较低维的目标空间生成候选位置，再经逆模型得到高维决策空间中的子代，
因而把搜索重点放在当前估计的 Pareto 集流形附近。

## 2. 为什么要采用局部逆模型

一个目标向量可能对应多个决策向量，所以全局逆映射未必是函数；Pareto 集还可能断裂、弯曲或包含多个分支。
若直接用一个全局 GP 表示 \(\mathbf{f}\mapsto\mathbf{x}\)，GP 的平滑性假设可能在分支之间产生并不存在的
“平均解”。IM-MOEA 因此采用分区后的局部建模：在每个目标空间子区域内，只拟合较简单、较连续的一段逆关系。

这种设计同时承担两项职责：

1. **分支隔离**：降低一对多逆映射造成的模式平均；
2. **多样性维护**：让不同前沿区域分别产生子代，避免样本集中在少数已收敛区域。

## 3. 单个局部逆 GP 的形式

对某个局部样本组 \(C_k=\{(\mathbf{f}_i,\mathbf{x}_i)\}\)，为每个决策变量建立一个独立的
Gaussian Process：

\[
  x_d = g_{k,d}(\mathbf{z})+\epsilon,
  \qquad d=1,\ldots,D,
\]

其中 \(\mathbf{z}\) 是该局部前沿上的低维目标坐标，\(\epsilon\) 是观测噪声。实际建模时通常先对局部
目标样本做中心化与主成分分析（PCA），在局部前沿的主方向上取得潜在坐标 \(\mathbf{z}\)，再以
\(\mathbf{z}\) 为 GP 输入、以第 \(d\) 个决策变量为输出。

给定一个新潜在点 \(\mathbf{z}_*\)，GP 给出预测分布

\[
  p(x_d\mid\mathbf{z}_*,C_k)
  =\mathcal{N}\!\left(\mu_{k,d}(\mathbf{z}_*),
                        \sigma^2_{k,d}(\mathbf{z}_*)\right).
\]

子代不是只能取预测均值；从这个预测分布采样，可把 GP 的预测不确定性转化为决策空间中的搜索扰动。
最后需把生成的每个决策变量截断或修复到问题定义域内。

> 独立输出 GP 没有显式建模各决策变量之间的条件相关性；变量之间的结构主要由共同输入
> \(\mathbf{z}\) 与训练样本间接保持。这是实现简单、代价可控，但也是方法的一个限制。

## 4. 一代演化的完整过程

可以把算法的一代概括为以下流水线：

1. **评价与选择建模样本**：评价当前种群，依据非支配关系及多样性准则保留优良解。
2. **目标空间分组**：按目标向量的邻近关系把样本分成若干局部组，使每组近似一段连续前沿。
3. **局部降维**：对每组目标向量做 PCA，得到该局部 Pareto 前沿的潜在坐标，并记录正、逆投影所需参数。
4. **训练逆 GP**：每个局部组、每个决策变量训练一个 GP，即一组共有 \(D\) 个标量输出模型。
5. **在潜在空间采样**：在各组已有潜在坐标的覆盖范围内（并可略作外扩）产生新点。区间内采样偏向插值，
   边界外扩则用于探索尚未覆盖的前沿。
6. **逆预测生成子代**：用各 GP 的后验均值和方差生成决策变量，组成完整决策向量并执行边界修复。
7. **真实目标评价**：将子代代回原始优化问题，而不是把逆模型预测当成最终适应度。
8. **环境选择**：合并父代与子代，根据收敛性和分布性选出下一代；随后重复建模与采样，直至评价预算耗尽。

对应的抽象伪代码为：

```text
P <- initialize_and_evaluate(N)
while evaluation budget remains:
    S <- select_training_solutions(P)
    groups <- partition_in_objective_space(S)
    Q <- empty
    for each group C in groups:
        z, projection <- local_PCA(objectives(C))
        for d = 1..D:
            GP[d] <- fit(z, decision_variable_d(C))
        for each sampled latent point z* allocated to C:
            x*[d] <- sample_or_predict(GP[d], z*) for d = 1..D
            Q <- Q union repair_to_bounds(x*)
    evaluate_true_objectives(Q)
    P <- environmental_selection(P union Q, N)
return nondominated(P)
```

## 5. 收敛、分布与探索分别来自哪里

| 目标 | 主要机制 |
| --- | --- |
| 向 Pareto 集收敛 | 逆模型仅用当前优良解训练；预测把新样本放到所学 Pareto 集附近 |
| 沿 Pareto 前沿铺开 | 目标空间分组、各组的子代配额以及局部潜在空间采样 |
| 局部探索 | GP 后验方差采样，而非始终只用均值 |
| 前沿延伸 | 对局部潜在坐标的采样范围作有限外推 |
| 防止模型误差累积 | 每个子代都用真实目标函数评价，再由环境选择纠错 |

因此，GP 不替代真实评价；它在这里是**生成模型/繁殖算子**。这一点与以 GP 近似昂贵目标函数、再用 acquisition
function 选择评价点的贝叶斯优化不同。

## 6. 实现时最容易混淆的细节

1. **逆模型的输入不是任意目标向量**：候选输入应位于局部前沿的低维近似上；对整个目标包围盒盲目采样会制造大量
   不可达目标点。
2. **必须局部化**：一个全局 GP 很容易跨越不连续 Pareto 分支并输出折中但劣质的决策点。
3. **标准化很重要**：目标和决策变量量纲不同时，应在聚类、PCA 和 GP 拟合前缩放，并在生成后正确反变换。
4. **超参数训练是主要开销之一**：若每代有 \(K D\) 个 GP，朴素 GP 的三次样本复杂度会十分明显；可限制每组
   样本数、复用上一代超参数或采用稀疏近似。
5. **小样本组需降级处理**：样本不足以进行 PCA/GP 拟合时，应合并邻组，或退化到交叉、变异等常规繁殖算子。
6. **边界修复不可省略**：独立 GP 的随机预测可能越过决策上下界。
7. **潜在维数应与局部前沿维数匹配**：双目标问题的前沿通常局部为一维；多目标问题一般需要保留更多主成分，
   不应无条件固定为一维。

## 7. 方法的适用性与局限

该方法特别适合“目标维数显著小于决策维数，且 Pareto 集可由若干局部平滑片段描述”的问题。它的主要风险包括：

- 目标空间局部相近的解在决策空间仍可能属于不同分支；
- 早期种群对前沿覆盖很差时，逆模型只会利用错误或狭窄的流形；
- 高度不连续、退化或有大量等价决策解的问题会强化逆映射的一对多性质；
- 多目标、高潜在维数下，采样和 GP 训练都会受到维数灾难影响；
- 独立输出 GP 不能直接表达决策变量之间的联合不确定性。

工程实现中应保留一部分常规变异子代或随机探索，并监控每组样本数、核矩阵条件数、预测方差与越界率，避免整个
搜索过程完全依赖尚未成熟的逆模型。

## 8. 后续复现时的核对清单

上述内容给出了逆 GP 的原理和算法骨架。若要逐行复现论文实验，还应对照论文算法框与作者实现，固定以下细节：

- 环境选择的确切排序及拥挤度规则；
- 分组方法、组数及每组子代配额；
- PCA 保留维数及外推区间；
- GP 的核函数、噪声项、超参数优化和数值稳定项；
- 使用后验均值还是后验采样，以及二者的比例；
- 小样本、重复点、奇异核矩阵和变量越界的处理；
- 论文各测试问题使用的种群规模、终止预算及独立运行次数。

这些属于可复现实验参数，不应从“逆 GP”这一概念本身臆测；实现前需要以论文原文或官方代码为准。
